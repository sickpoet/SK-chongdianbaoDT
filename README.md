# chongdianbaoDT

两件轻量小工具：

- **国庆旅游热度榜**：查各地国庆期间旅游热度
- **共享充电宝投放分析**：搜地区、按人口测算柜机数与代理名额、导出投放简报

在线地址：<https://dt-self-theta.vercel.app>
